# Cashtory: videos terminados

Repositorio público con los videos finales del canal Cashtory. Se usa para que Metricool los descargue al programarlos.
Solo se suben piezas aprobadas para publicar. Los guiones, la estrategia y el estado del proyecto están en el repositorio privado.

- 01-madoff/: piloto Bernard Madoff (video largo, Shorts 2 y 3, miniatura y créditos de imágenes de Pixabay).
- farmazon/: 3 videos de Fármazon (recordatorio de medicamentos por Telegram, marca de la Droguería Farmacenter), para Metricool. Origen: repositorio privado, proyectos/adherencia-farmaceutica/materiales/anuncios-farmazon.
